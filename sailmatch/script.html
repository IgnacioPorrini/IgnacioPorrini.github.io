Instalar el script desde el celular

Unos 5 minutos, una sola vez. Conviene tener esta página abierta en una pestaña y script.google.com en otra.

1. Copiar el código

Tocá el botón: copia todo el script de una vez.


        


        
    
            
  1. Abrí script.google.com en Chrome. En el menú ⋮ marcá Sitio de escritorio (o “Solicitar sitio de escritorio”). Se crea un proyecto nuevo.
    2. 
            
  2. Tocá dentro del editor, mantené apretado para Seleccionar todo, y Pegar (reemplaza lo que había). Tocá el ícono de guardar 💾.
    3. 
            
  3. Arriba, en el selector de funciones, elegí configurar y tocá Ejecutar. Google pide permisos: tu cuenta → Configuración avanzada → Ir a … (no seguro) → Permitir. Es normal: el script es tuyo y no está verificado por Google.
    4. 
            
  4. Implementar → Nueva implementación → engranaje → Aplicación web. Ejecutar como: Yo. Quién tiene acceso: Cualquier persona. Tocá Implementar.
    5. 
            
  5. Copiá la URL de la aplicación web (termina en /exec) y mandásela a Claude.
